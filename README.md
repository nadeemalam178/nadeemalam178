**[Shalimar Store](https://github.com/nadeemalam178/shalimar-store)** is a production-grade, dual-mode general store & grocery mobile application built with Flutter & Dart. It brings traditional neighborhood shopping into the digital era with **zero gateway fees**, **direct WhatsApp ordering**, **zero-fee UPI payments**, **Google Firebase real-time cloud catalog sync**, **in-app direct OTA updates**, and an **ID & Password protected owner management panel**.

- ⚡ **Dual-Mode Architecture:** Customer catalog browsing + Owner/Admin inventory manager in a single unified app.
- 📲 **In-App Direct OTA Updates:** Update downloads happen directly inside the app with a real-time byte progress bar and 1-tap native package installer launch (`open_filex`) with zero browser redirects.
- ☁️ **Google Firebase Cloud Sync:** Full integration with Google Firebase Firestore (`shalimar-store`) on the Free Spark Tier. Products, stock levels, and prices sync in real time across owner and customer phones.
- 🔔 **Dual-Tier Push & Local Notification Engine:**
  - *"🔔 Notify Me When in Stock":* Customers can subscribe to restock alerts (`restock_<productId>`) on out-of-stock items.
  - Automatic restock notification dispatch when the store owner toggles stock back in the Admin Panel.
  - Native local heads-up order dispatch alerts upon placing WhatsApp orders.
  - Store broadcast topic announcements (`store_broadcast`).
- 🌓 **Complete AMOLED Dark Theme Overhaul:** All customer tabs, navigation docks, floating cart bars, and admin screens redesigned using adaptive semantic tokens for true `#121212` / `#1E1E1E` AMOLED aesthetics.
- 🧹 **Production Admin Hardening:** Pure live store inventory only — demo quick-loader stripped for production reliability.
- 🔍 **Interactive Product Detail View:** Tap any card for full details, smooth hero animation, and multi-image swipeable carousel.
- 💡 **Smart Recommendations:** Dual horizontal carousels for *"More Like This"* (category alternatives) and *"More For You"* (staples).
- 🔤 **Plus Jakarta Sans Typography:** High-clarity geometric typography tailored for modern retail apps.
- ⚡ **Lightweight Performance:** Constrained image decoding caches (~85% RAM savings) and optimized shaders for smooth 60 FPS on budget phones.
- ⌨️ **Gliding Keyboard Ergonomics:** Admin login modal dynamically floats above the on-screen keyboard.
- 🛍️ **Persistent Shopping Cart:** Items stay safely saved in local storage until ordered on WhatsApp or cleared.
- 🔍 **Pinned / Freezed Search Bar:** Always accessible at the top while scrolling 1,000+ items.
- 📷 **Direct Camera & Gallery Photo Upload:** Live photo capture and upload for inventory items.
- 📊 **Out-of-Stock Dashboard:** Category-wise breakdown with instant 1-tap Restock.
- 🏷️ **Dynamic Categories:** Admin can add new departments on the fly, instantly reflected for all users.
- 📦 **Split-per-ABI APKs:** Lightweight builds (~23–27 MB) signed with APK Signature Scheme v1–v4.
