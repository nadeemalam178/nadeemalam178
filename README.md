### 🚀 Featured Project: [DROPZONE](https://github.com/nadeemalam178/dropzone-android)

> **Save anything. Find it when it matters.**

**[DROPZONE](https://github.com/nadeemalam178/dropzone-android)** is an offline-first personal digital inbox and local vault for Android. Instantly capture web links, photos, PDFs, notes, and documents from any app via the native system share sheet.

- **100% Offline-First:** Zero cloud servers, zero trackers, full data privacy.
- **Modern Android Stack:** Built with Jetpack Compose, Material 3, Room Database, Kotlin Coroutines, and Coil.
- **Secure Vault:** Biometric authentication and standalone ZIP backup & restore with SHA-256 integrity verification.
- **In-App Auto Updates:** Seamless GitHub Releases-based update mechanism.
